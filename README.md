# Playwright Workshop — AI-First E2E Testing

Hands-on workshop to learn **Playwright** from scratch using AI as your copilot. You'll build end-to-end tests against a real FastAPI app, in both **TypeScript** and **Python**.

## What You'll Learn

- Accessible locators (`getByRole`, `getByLabel`, `getByTestId`)
- Page Object Model (POM) — encapsulating interactions
- Fixtures with automatic setup/teardown
- Network mocking with `page.route()`
- Debugging: trace viewer, `page.pause()`, reports
- AI agents: planner, generator, healer
- Playwright MCP — Copilot controls the browser

## Prerequisites

- Node.js 18+ and Python 3.11+
- VS Code with GitHub Copilot
- Basic knowledge of HTML and the terminal

## Setup

```bash
# 1. Install dependencies
npm install

# 2. Install Playwright browsers and system dependencies
npx playwright install chromium
npx playwright install-deps chromium

# 3. Activate the Python environment
source .venv/bin/activate

# 4. Verify the app runs
uvicorn app.main:app --reload
# → http://localhost:8000
```

## Structure

| Folder | Purpose |
|---|---|
| `app/` | FastAPI Todo App (the app under test) |
| `tests/` | Your work — TypeScript specs |
| `tests-python/` | Your work — Python specs |
| `solutions/` | Full reference (do not modify) |
| `specs/` | Test plans generated by the planner |

## How to Use

1. Open [INSTRUCTIONS.md](INSTRUCTIONS.md) — it has ready-to-use prompts for Copilot Chat
2. Follow the phases in order (1→9)
3. Each phase includes validation with real commands
4. If you get stuck, check `solutions/`

## Quick Commands

```bash
npx playwright test                    # Run all TS tests
npx playwright test --headed           # With visible browser
npx playwright test --ui               # Visual interactive mode
npx playwright codegen localhost:8000  # Record actions
pytest tests-python/ -v                # Python tests
```
